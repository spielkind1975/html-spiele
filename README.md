# html-spiele

Kleine Browser-Programme, jeweils als einzelne HTML-Datei ohne Abhängigkeiten.

| Datei | Inhalt |
|---|---|
| `tetris.html` | Tetris-Klon mit Hold, Vorschau, Ghost-Stein, Leveln und Rekord. Steuerung per Tastatur oder Touch. |
| `atemraum.html` | Atem-App: pulsierender Kreis, vier Atemrhythmen (Kohärent, Länger aus, Box, 4-7-8), ruhiger Klang per Web Audio, vier Farbstimmungen. |

Starten: Datei im Browser öffnen. Mit GitHub Pages laufen beide auch online.
